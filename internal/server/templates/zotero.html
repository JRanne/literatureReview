Zotero desktop on this computer {{if .Desktop}}running{{else}}not detected{{end}}

The app creates the collection you name (or reuses it), adds each included paper as an item with full metadata, tags, the citation key, a note with the extracted aspects, and stores the PDF in Zotero's own storage (no cloud quota), all through Zotero's local API. The first time, Zotero shows a permission dialog: choose Always Allow so later exports run without asking. Requires Zotero 7 with the local API enabled (Settings → Advanced → “Allow other applications on this computer to communicate with Zotero”).
